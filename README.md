# 抖音视频逐帧控制扩展

一个 Chrome 浏览器扩展，为抖音视频播放器添加逐帧前进和后退功能。

## 🚀 功能特性

- **逐帧控制**：前进/后退一帧（约0.04秒）
- **视频截图**：一键截图当前帧，自动下载为 PNG 图片
- **键盘快捷键**（在视频页面内）：
  - `D` 或 `←` - 上一帧
  - `F` 或 `→` - 下一帧
  - `G` - 截图当前帧 💾
  - `Space` - 暂停/播放
- **可拖拽面板**：拖动控制面板到任意位置，位置自动保存
- **智能暂停控制**：点击进度条后继续保持暂停状态
- **悬浮控制面板**：显示当前帧和时间信息
- **自动检测**：自动查找视频元素
- **自适应**：支持抖音Web端各种播放器

## 📦 安装方法

### 开发者模式安装

1. 下载本扩展文件夹到本地
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`
3. 右上角开启 **"开发者模式"**
4. 点击 **"加载已解压的扩展程序"**
5. 选择本文件夹的路径

### 安装后配置

1. 点击扩展图标，确保状态显示为"就绪"
2. 访问任意抖音视频页面（如：https://www.douyin.com/video/xxxxxx）

## 🎮 使用方法

1. **打开抖音视频页面**
2. **键盘快捷键控制**：
   - `D` 或 `←` - 上一帧
   - `F` 或 `→` - 下一帧
   - `G` - 截图当前帧 💾
   - `Space` - 暂停/播放
3. **鼠标控制**：
   - 页面底部会显示控制面板
   - 点击"⏮ -1帧"后退一帧
   - 点击"⏭ +1帧"前进一帧
   - 点击"📷"按钮截图当前帧

## 🔧 技术原理

本扩展通过以下方式实现逐帧控制：

### 1. 视频元素劫持
- 在抖音页面中查找 `video` 元素
- 监听视频时间更新事件
- 注入自定义控制逻辑

### 2. 时间精确控制
- 使用 `videoElement.currentTime` API 精确设置时间
- 帧步进设置为 0.04 秒（对应 25fps）
- 使用 `requestAnimationFrame` 确保渲染同步

### 3. 用户界面
- Content Script 注入控制面板
- 键盘事件监听
- 视觉反馈提示

## ⚙️ 高级配置

### 修改帧步进精度
如果需要调整步进大小，可以在扩展中修改：

1. 进入 `content.js`
2. 找到 `const FRAME_STEP = 0.04;`
3. 调整为所需值（单位：秒）

```
// 常见的帧率对应步进值
30fps: 0.0333
25fps: 0.0400  
24fps: 0.0417
60fps: 0.0167
```

### 调试模式
在控制台可以访问扩展的 API：

```javascript
// 检查视频元素
window.douyinFrameControl.getVideoElement();

// 获取当前时间
window.douyinFrameControl.getCurrentTime();

// 手动步进（前进/后退）
window.douyinFrameControl.stepFrame(1);  // 前进
window.douyinFrameControl.stepFrame(-1); // 后退
```

## 🔍 问题排查

### 常见问题

1. **扩展没有反应**
   - 确保在抖音视频页面（URL包含 douyin.com）
   - 刷新页面后等待几秒
   - 检查控制台是否有错误信息

2. **快捷键不工作**
   - 确认不在输入框中
   - 检查键盘布局
   - 重新加载扩展

3. **控制面板不显示**
   - 确保视频已加载
   - 手动检查是否有视频元素：`document.querySelector('video')`

### 调试步骤

1. 打开 Chrome 开发者工具（F12）
2. 切换到 Console 面板
3. 检查是否有错误信息
4. 输入 `document.querySelectorAll('video')` 查看视频元素

### 图标

深色圆角磁贴 + 一张竖版白色卡片（276x312，和姊妹扩展「图文取图」同比例、同轮廓），卡片里用**负空间**挖出逐帧步进的 `|▶`；卡片和磁贴边框都偏一道抖音青 `#42D2CB` / 品红 `#FE2C55`（抖音的色差错位质感）。两个扩展因此成一对：一样的磁贴和卡片轮廓，只是挖空的符号不同——这边是步进 `|▶`（逐帧），那边是下载箭头（取图）。

没用汉字（密集笔画 40px 以下必糊），也没用最初的横屏 16:9 胶片格（在方形磁贴里显得矮胖），只留实心和负空间。Chrome 本地 unpacked 扩展最大只取到 48（工具栏和拼图菜单取 16，高分屏取 32，`chrome://extensions` 列表与详情页取 48），128 只有上架商店时才用，所以四档统一成同一个构图，只按尺寸调细节：

| 尺寸 | shift 色差 | rimAlpha 边框双色 | weight 竖条笔画 | bar 步进竖条 |
| --- | --- | --- | --- | --- |
| 16 | 0 | 60 | 1.4 | 关（16px 放不下两个元素） |
| 32 | 5 | 80 | 1.15 | 开 |
| 48 | 8 | 100 | 1.0 | 开 |
| 128 | 14 | 130 | 0.85 | 开 |

改样式就编辑 `tools/make-icons.ps1` 里的 `$plans` 和 `$CYAN`/`$PINK`/`$INK`/`$TILE_*`，重跑：

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\make-icons.ps1
```

只用 Windows 自带的 GDI+（`System.Drawing`），无第三方依赖：先画 512 矢量母版再 `HighQualityBicubic` 降采样。改完要在 `chrome://extensions` **移除后重新加载**才会换图标，光点刷新 ↻ 常常不生效；manifest 的 `version` 可以用来确认到底加载了哪一版。
